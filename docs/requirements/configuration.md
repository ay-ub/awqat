# Configuration

## Goal

Allow users to configure Awqat once and reopen it without repeating setup.

## Requirements

- Store the selected country, region, city, calculation method, and madhab.
- Store display preferences.
- Store notification preferences.
- Validate configuration before use.
- Report missing, invalid, or incompatible configuration explicitly.

## Acceptance criteria

- A configured installation opens directly to the main screen.
- The user can change the city and calculation settings.
- Invalid configuration can be repaired from the application.
